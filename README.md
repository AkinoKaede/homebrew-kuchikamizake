# 🍺Kuchikamizake

A flavored [Homebrew](https://brew.sh/) tap, providing various kinds of applications.

Spot an error? Find a place which can be improved? Or your favorite application isn't included? Feel free to [submit an issue](https://github.com/akinokaede/homebrew-kuchikamizake/issues/new) or make a pull request!

## Usage

```sh
brew tap akinokaede/kuchikamizake
brew install <formula>
brew install --cask <cask>

# Or just
brew install akinokaede/kuchikamizake/<formula>
brew install --cask akinokaede/kuchikamizake/<cask>
```
